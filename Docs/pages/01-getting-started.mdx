# Getting started

## Requirements

:::info[.NET 10 SDK and C# 14]

Mockolate generates its mocks with C# 14 extension members, so you need the [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) to build your tests. If your test project pins `<LangVersion>`, it must be `14` or later (or `latest`).

:::

Your test projects can still target any supported framework: .NET Standard 2.0, .NET 8, .NET 10 or .NET Framework 4.8.

## Install the package

<PackageInstall package="Mockolate" />

Mockolate works with every test framework (xUnit, NUnit, MSTest, TUnit, …). The package contains the source generator and the analyzers, so there is nothing else to configure.

## Write your first test

Suppose your code depends on a chocolate dispenser:

```csharp title="Production code"
public interface IChocolateDispenser
{
    bool Dispense(string type, int amount);
}

public class VendingMachine(IChocolateDispenser dispenser)
{
    public string Buy(string type, int amount)
        => dispenser.Dispense(type, amount) ? "Enjoy!" : "Sold out";
}
```

To test `VendingMachine` without a real dispenser, create a mock of `IChocolateDispenser`, tell it how to behave, and check afterwards how it was used:

```csharp title="VendingMachineTests.cs"
using Mockolate;
using Mockolate.Verify;
using static aweXpect.Expect;

public class VendingMachineTests
{
    [Test]
    public async Task Buy_WhenChocolateIsAvailable_ShouldDispenseIt()
    {
        IChocolateDispenser dispenser = IChocolateDispenser.CreateMock();
        dispenser.Mock.Setup.Dispense("Dark", It.IsAny<int>()).Returns(true);
        VendingMachine sut = new VendingMachine(dispenser);

        string result = sut.Buy("Dark", 4);

        await That(result).IsEqualTo("Enjoy!");
        dispenser.Mock.Verify.Dispense("Dark", 4).Once();
    }
}
```

- `CreateMock()` is generated for every type you mock, so IntelliSense shows it as soon as you type `IChocolateDispenser.`.
- Every mock has a `Mock` property that gives access to `Setup`, `Verify` and `Raise`.
- `It.IsAny<int>()` is a [parameter matcher](./06-parameter-matching.md). Plain values like `"Dark"` match by equality.
- `.Once()` throws a `MockVerificationException` when the call count does not match. It lives in the `Mockolate.Verify` namespace.

:::note[aweXpect in the examples]

The test uses [TUnit](https://tunit.dev/), and the examples in this documentation check results with [aweXpect](/aweXpect/) (`await That(...)`). aweXpect is optional: Mockolate works with any test framework and assertion library. If you use aweXpect, the [aweXpect.Mockolate](/aweXpect/extensions/aweXpect.Mockolate/) extension also lets you write verifications as awaitable expectations: `await That(dispenser.Mock.Verify.Dispense("Dark", 4)).Once();`.

:::
