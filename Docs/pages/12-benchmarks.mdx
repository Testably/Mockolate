# Benchmarks

These benchmarks measure Mockolate's runtime overhead against
[Moq](https://github.com/devlooped/moq),
[NSubstitute](https://nsubstitute.github.io/),
[FakeItEasy](https://fakeiteasy.github.io/),
[TUnit.Mocks](https://github.com/thomhurst/TUnit/) and
[Imposter](https://github.com/themidnightgospel/Imposter) for the same end-to-end mocking flow.

<Tabs groupId="mockolateBenchmark" className="benchmark-tabs">

<TabItem value="Complete" label="Complete test" default>

A complete unit test: a `ChocolateShop` sells chocolate to three customers with four mocked dependencies. The mocks are set up with exact values, argument matchers and a property, and verified afterwards. Each mocked member is called two or three times, because the last sale fails at the dispenser.

<MockolateBenchmarkResult name="Complete" />

```csharp
IChocolateDispenser dispenser = IChocolateDispenser.CreateMock();
ICashRegister register = ICashRegister.CreateMock();
IClock clock = IClock.CreateMock();
IReceiptPrinter printer = IReceiptPrinter.CreateMock();
dispenser.Mock.Setup.Dispense("Dark", 3).Returns(true);
register.Mock.Setup.Charge(It.IsAny<string>(), It.IsAny<decimal>()).Returns(true);
clock.Mock.Setup.Now.InitializeWith(Now);

ChocolateShop shop = new(dispenser, register, clock, printer);
shop.Sell("Alice", "Dark", 3);
shop.Sell("Bob", "Dark", 3);
shop.Sell("Carol", "Milk", 2);

register.Mock.Verify.Charge(It.IsAny<string>(), It.IsAny<decimal>()).Exactly(3);
dispenser.Mock.Verify.Dispense("Dark", 3).Twice();
printer.Mock.Verify.Print("Alice", It.IsAny<string>()).Once();
```

<TabItem value="Unconfigured" label="Without setup">

Use a mock without any setup: call two methods that return a value and one that returns nothing, and read a property and an indexer, each `N` times. Every member answers with its default value. Then verify one method ran exactly `N` times.

<MockolateBenchmarkResult name="Unconfigured" />

```csharp
IChocolateWarehouse warehouse = IChocolateWarehouse.CreateMock();

for (int i = 0; i < N; i++)
{
    warehouse.CountBars("Dark");
    warehouse.FindShelf("Dark", 3);
    warehouse.Restock("Dark", 3);
    _ = warehouse.IsOpen;
}

warehouse.Mock.Verify.CountBars(It.IsAny<string>()).Exactly(N);
```

<details>
<summary>How these numbers are measured</summary>

- **Suite**: [`Mockolate.Benchmarks`](https://github.com/Testably/Mockolate/tree/main/Benchmarks/Mockolate.Benchmarks) driven by [BenchmarkDotNet](https://benchmarkdotnet.org/).
- **Job**: `MediumRun` with the in-process toolchain.
- **Runner**: `ubuntu-latest` GitHub Actions agent, refreshed on every push to `main`.
- **Parameters**: Without setup, Method, Property and Indexer repeat their inner body 1, 10 or 1000 times (`N=1`, `N=10`, `N=1000`) to separate the fixed cost from the cost per call and to show how the cost grows for a member that is called many times. Each value can be selected in the chart.
- **Charts**: every multiple is relative to Mockolate, and bars longer than four times the fastest library are cut so the others stay comparable. Lower is better.
- **Trend**: the recent runs compare each library with Mockolate in the same run, so the line does not depend on the speed of the runner. The dashed line marks equal time.

</details>
